# Python - More Classes and Objects

## Description

This project continues the study of Object-Oriented Programming (OOP) in Python.
It focuses on classes and objects, class attributes, instance attributes,
properties, class methods, static methods, and special methods such as
`__str__` and `__repr__`.

The goal is to understand how classes interact with objects and how to design
clean, reusable, and maintainable code following Python conventions.
