The ``5-text_indentation`` module
==================================

Using ``text_indentation``:
---------------------------

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Test with standard text containing formatting characters:
    >>> text_indentation("Hello. World")
    Hello.
    <BLANKLINE>
    World

Test with multiple consecutive target characters and no spaces:
    >>> text_indentation("Hi?Yes:Ok")
    Hi?
    <BLANKLINE>
    Yes:
    <BLANKLINE>
    Ok

Test with heavy leading, trailing, and inline spaces:
    >>> text_indentation(" Hello. World? Python: Test")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>
    Python:
    <BLANKLINE>
    Test

    >>> text_indentation(12345)
