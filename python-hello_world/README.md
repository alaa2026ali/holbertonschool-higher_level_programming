# Python - Hello, World

This project is part of the Holberton School Higher Level Programming curriculum.

The goal of this project is to learn the basics of Python programming, including:

* Using the Python interpreter
* Writing and executing Python scripts
* Printing text and variables
* Working with strings
* String indexing and slicing
* Using formatted strings
* Following the Python style guide with pycodestyle

## Requirements

* Ubuntu 20.04 LTS
* Python 3.8
* pycodestyle 2.7
* All files must be executable
* All files must end with a new line

## Learning Objectives

By completing this project, students should be able to:

* Use the Python interpreter
* Create and run Python scripts
* Print text and variables
* Manipulate strings
* Understand indexing and slicing
* Write code that follows Python coding standards
