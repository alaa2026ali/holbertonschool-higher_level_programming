# Python - if/else, loops, functions

## Description

This project covers the basics of Python control flow and functions, including:

- if / else statements
- logical operators
- loops (for, while)
- range function
- functions and return values

The goal is to understand how to control the flow of a program and write reusable code using functions.

---

## Learning Objectives

By the end of this project, you should be able to explain:

- What are if, else, and elif statements
- How to use comparison and logical operators
- How to use loops in Python
- How to use the range() function
- What functions are and how to define them
- What return means in a function
- The difference between print and return
