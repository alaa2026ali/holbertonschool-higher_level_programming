# Python - Exceptions

## Description
This project introduces exception handling in Python. It covers the use of `try`, `except`, `else`, `finally`, and raising exceptions with `raise`. The goal is to write programs that handle errors gracefully without crashing.

## Learning Objectives
At the end of this project, I am able to explain:
- Why Python programming is awesome
- What the difference is between errors and exceptions
- What exceptions are and how to use them
- When exceptions need to be used
- How to correctly handle an exception
- What the purpose of catching exceptions is
- How to raise a built-in exception
- When to implement a clean-up action after an exception

## Requirements
- **Allowed editors:** vi, vim, emacs
- **Environment:** All files interpreted/compiled on Ubuntu 20.04 LTS using Python 3.8.5
- **Formatting:** 
  - All files must end with a new line
  - The first line of all files must be exactly: `#!/usr/bin/python3`
  - Code follows `pycodestyle` guidelines (version 2.8.*)
- **Execution:** All files must be executable (`chmod +x`)
- **Validation:** File length tested using `wc`

## Files

| File | Description |
| :--- | :--- |
| `0-safe_print_list.py` | Prints x elements of a list safely |
| `1-safe_print_integer.py` | Prints an integer safely |
| `2-safe_print_list_integers.py` | Prints only integers from a list |
| `3-safe_print_division.py` | Divides two integers and handles errors |
| `4-list_division.py` | Divides list elements safely |
| `5-raise_exception.py` | Raises a type exception |
| `6-raise_exception_msg.py` | Raises a name exception with a message |

## Setup and Execution

1. Make sure all Python files are executable:
```bash
chmod +x *.py
```

2. To test any file (e.g., file `0`), run its corresponding main test script:
```bash
./0-main.py
```
