# SQL Introduction

This project introduces the fundamentals of SQL and relational databases using MySQL.

## Learning Objectives

- Create and manage databases
- Create and modify tables
- Insert, update, delete, and retrieve data
- Use basic SQL queries and conditions
- Understand relational database concepts

## Requirements

- Ubuntu 20.04 LTS or later
- MySQL 8.0
- SQL scripts must end with a new line
- All files start with a comment describing the task
