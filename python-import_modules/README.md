# Python - Import & Modules

## Description

This project introduces Python modules and importing. It covers how to create modules, import functions and variables from other files, use command-line arguments, and organize Python code across multiple files.

## Learning Objectives

* Import functions from another file
* Use imported functions
* Create modules
* Use the built-in `dir()` function
* Prevent code from being executed when imported
* Use command-line arguments with Python programs

## Requirements

* Ubuntu 22.04 LTS
* Python 3.10
* Pycodestyle 2.7
* All files are executable
* All files start with `#!/usr/bin/python3`
