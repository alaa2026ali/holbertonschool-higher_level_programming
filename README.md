# holbertonschool-higher_level_programming

This repository contains projects completed as part of the Holberton School Higher Level Programming curriculum.

The main focus of this repository is learning Python programming and higher-level software development concepts.

Topics covered include:

* Python basics
* Variables and data types
* Strings
* Control flow
* Functions
* Modules
* Data structures
* Object-Oriented Programming (OOP)
* Exceptions
* File handling
* Test-driven development
* SQL and databases

All projects are written in Python 3 and follow Holberton School requirements and coding standards.
