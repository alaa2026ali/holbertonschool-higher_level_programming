Python - More Data Structures: Set, Dictionary
📚 Description

This project covers advanced Python data structures, mainly sets and dictionaries, and how to manipulate them efficiently.

🎯 Learning Objectives
Use sets and understand unique elements
Perform set operations (union, intersection, difference)
Work with dictionaries (key-value pairs)
Add, update, and delete dictionary elements
Use .get() safely
Iterate over sets and dictionaries
🧠 Concepts
🔹 Set

Unordered collection of unique elements.

a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)
print(a & b)
print(a - b)
🔹 Dictionary

Key-value data structure.

person = {"name": "Alaa", "age": 20}
print(person.get("name"))
