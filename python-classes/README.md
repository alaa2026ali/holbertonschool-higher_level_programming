# Python - Classes and Objects

## Description

This project introduces the fundamentals of Object-Oriented Programming (OOP) in Python. It covers the concepts of classes, objects, attributes, methods, encapsulation, information hiding, properties, getters, and setters.

The goal is to understand how to create and use classes and objects while following Python's best practices and coding standards.

## Learning Objectives

By the end of this project, you should be able to explain:

* What Object-Oriented Programming (OOP) is
* What a class is
* What an object and an instance are
* The difference between a class and an object
* What attributes and methods are
* The purpose of the `self` keyword
* The role of the `__init__` method
* The difference between public, protected, and private attributes
* Data abstraction, encapsulation, and information hiding
* How to use properties, getters, and setters
* How Python handles attributes and instances

## Requirements

* Ubuntu 20.04 LTS
* Python 3.8.5
* All files must be executable
* All files must end with a new line
* Code must follow pycodestyle (version 2.7.*)
* Every module, class, and function must contain proper documentation
