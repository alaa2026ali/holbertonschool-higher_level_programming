# Python - Data Structures: Lists, Tuples

## Description

This project is part of the Holberton School curriculum. It focuses on Python data structures, specifically lists and tuples. The project introduces fundamental concepts such as indexing, slicing, list methods, list comprehensions, tuple packing, sequence unpacking, and the use of sequences in Python.

## Learning Objectives

By completing this project, I learned:

* What lists are and how to use them
* The differences and similarities between strings and lists
* Common list methods and their usage
* How to use lists as stacks and queues
* What list comprehensions are and how to use them
* What tuples are and how to use them
* When to use tuples versus lists
* What a sequence is
* What tuple packing is
* What sequence unpacking is
* How to use the `del` statement
