# Python - Object-relational Mapping

## Description
This project introduces Object-relational Mapping (ORM) in Python. It covers connecting Python to a MySQL database using MySQLdb and SQLAlchemy to perform database operations.

## Learning Objectives
- Connect Python to MySQL
- Execute SQL queries using MySQLdb
- Use SQLAlchemy ORM
- Create, read, update, and delete database records
- Understand relationships between Python objects and database tables

## Requirements
- Ubuntu 22.04 LTS
- Python 3.10
- MySQL 8.0
- pycodestyle (2.7.*)
- MySQLdb
- SQLAlchemy
