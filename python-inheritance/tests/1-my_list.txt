===============================
How to use 1-my_list module
===============================

First, import the class:
    >>> MyList = __import__('1-my_list').MyList

Test basic functionality with a mix of unsorted integers:
    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Test with an empty list:
    >>> empty_list = MyList()
    >>> empty_list.print_sorted()
    []

Test with negative numbers and duplicates:
    >>> mixed_list = MyList([3, -1, 2, -5, 2])
    >>> mixed_list.print_sorted()
    [-5, -1, 2, 2, 3]
    >>> print(mixed_list)
    [3, -1, 2, -5, 2]

Test with already sorted list:
    >>> sorted_list = MyList([1, 2, 3, 4])
    >>> sorted_list.print_sorted()
    [1, 2, 3, 4]
